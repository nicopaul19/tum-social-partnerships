Enrichment Crawl Strategy

The agent starts from the NGO homepage, discovers internal links, and fetches them in priority order. Defined in TARGET_PAGES in ngo_enrichment_agent.py:

#Page typeURL keyword patterns searched
1Impressumimpressum, imprint, legal
2Aboutueber-uns, über uns, about-us, wer-wir-sind
3Team / Staffteam, unser-team, staff, mitarbeiter
4Leadership / Boardvorstand, leadership, geschäftsführung, gremien
5Contactkontakt, contact, ansprechpartner
6Digital / Innovationdigital, innovation, technologie
7Org structureorganisation, struktur, organigramm

For each page, agent fetches first 5 000 chars of stripped body text → GPT-4o structured extraction → ContactExtraction Pydantic with contact_name, contact_role, contact_email, email_confidence (0–10), contact_notes.

German Copywriter Rules

The full brief is SYSTEM_PROMPT_TEMPLATE in ngo_copywriter_agent.py. Key rules at a glance:

RRR structure (mandatory)

ParaContentKey constraint
1Greeting + intro (sender, TUM Social AI) + appreciation for their work areaExactly ONE appreciation sentence. Use "sehr inspirierend!" as default phrase. Never "äußerst", "umfangreich", "von unschätzbarem Wert".
2What TUM Social AI does for nonprofitsOne sentence covering both internal AI (processes, reporting) and mission-related AI support.
3Personalized AI angle + openness to hear real challengesAI angle = example only ("könnte zum Beispiel"). Then explicitly invite them to share their actual bottlenecks.
4CTA + forwarding invite + closing"Hätten Sie Interesse an einem kurzen 20-minütigen Austausch?" Invite forwarding to IT/Digitalisierung/Innovation. Close: "Beste Grüße," then sender first name on next line.

Subject line format

TUM Social AI <> [NGO short name]: Pro-bono KI [optional 1-2 word German angle]

Examples:
  TUM Social AI <> WWF: Pro-bono KI Artenschutz
  TUM Social AI <> Caritas Köln: Pro-bono KI
  TUM Social AI <> IOM Germany: Pro-bono KI Integration

Style guardrails

  • Never use: "revolutionieren", "disrupten", "bahnbrechend", "Gamechanger", em dashes (—), en dashes (–).
  • Never claim TUM Social AI already worked with this specific NGO unless confirmed.
  • Never make up facts not present in the input data.
  • If no contact person → Liebes Team von [NGO Name], · Never "Sehr geehrte Damen und Herren".

Sender assignment

Even-index ranks (1, 3, 5…) → owner 0 · Odd-index (2, 4, 6…) → owner 1. Edit NGO_OWNERS list in ngo_copywriter_agent.py line 177 to change default owners or add a third sender.

How to Make Changes

Always test with --dry-run --limit 5 first. For prompt changes, read 5 generated emails in German before launching a live campaign.

Change scoring weights

Find the formula in ngo_partner_agent.py (search 0.35) and adjust multipliers — they must sum to 1.0:

# e.g. weight mission more heavily for a mission-specific campaign
total_score = 0.25 * size_score + 0.50 * mission_score + 0.25 * establishment_score

Change the qualification threshold or shortlist size

These are CLI flags — no code change needed:

python -m agents.ngo_partner_agent --csv my.csv --min-score 5 --top 40

Change scoring anchor points

Edit the bullet-point score guides in SYSTEM_PROMPT in ngo_partner_agent.py. Adding concrete German NGO names as calibration examples reliably improves score quality.

Add or reorder enrichment pages

Edit TARGET_PAGES in ngo_enrichment_agent.py (line 63). Each entry is a tuple of keyword patterns + page label. Move a tuple earlier in the list to raise its priority.

Change crawl timeout or delay

# ngo_enrichment_agent.py
REQUEST_TIMEOUT = 15   # seconds per request
FETCH_DELAY = 1.0      # seconds between requests — don't go below 0.5

Resume a failed enrichment run

python -m agents.ngo_enrichment_agent --start-from 20  # skips first 20 already done

Change email copy style or tone

Edit SYSTEM_PROMPT_TEMPLATE in ngo_copywriter_agent.py. Most-changed sections: STYLE RULES (banned words, tone), Email structure (paragraph constraints), SUBJECT LINE RULES.

Change email length limits

Edit the Pydantic field description strings in class NGOEmail in ngo_copywriter_agent.py.

Add a sender / change default owners

Edit NGO_OWNERS list (line 177). A 3-person list gives ~33/33/33 split. Pass --sender "Name" at runtime to override for a specific run.

Add a new prospect source beyond NGO.base

  1. Export from source (DZI, GlobalGiving, EU Transparency Register, etc.).
  2. Map columns: ngo_name, col href, work_area, sub_work_area, listing_locations.
  3. Save to data/inputs/ with a descriptive filename.
  4. Run --dry-run. If scores look miscalibrated, add sample orgs from that source as scoring examples in the prompt.

Improve email quality via the learnings loop

Add weak examples + improved versions to the Notion Copywriter Improvement Log (bad snippet / improved / reason / context). Distill processed learnings into data/prompts/outreach_learnings.md — auto-injected every run.

Common failure patterns: two appreciation sentences instead of one · AI angle stated as certainty not example · body over 170 words · subject line over 10 words · "revolutionieren" or "disruptiv" anywhere · "Sehr geehrte Damen und Herren".
