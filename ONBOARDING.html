TUM Social AI · Agent Infrastructure

Social Partnerships Agents

Complete technical reference for the NGO scoring, contact enrichment, German outreach generation, and Notion import pipeline. Covers every parameter, data flow, crawl strategy, and change guide a new student needs to operate and improve the system.

What This System Does

Score

A source CSV of NGOs is batch-scored 0–10 by GPT-4o across three weighted criteria. Top organizations advance to enrichment.

Enrich

For each ranked NGO the enrichment agent crawls up to 8 pages (homepage, impressum, team, leadership, contact, digital/innovation) to find the best senior contact and email.

Copywrite

Personalized German outreach emails are generated using the RRR framework (Relevance, Reward, Request) with strict tone rules, subject line format, and processed learnings.

Upload

Enriched NGOs and contacts are deduplicated and written to Notion Accounts + Contacts with campaign ID, score, AI angle, and suspected email.

Project Applications

Applying nonprofits from Project Requirements are analyzed with GPT-4o (GTM analysis, data readiness, tech stack) then linked to Notion Accounts + Product Owner.

Project application intake can stay scheduled. Campaign creation — scoring, enrichment, outreach — should always happen when someone deliberately decides to run a campaign.

Detailed Scoring Criteria

The GPT-4o system prompt (SYSTEM_PROMPT in ngo_partner_agent.py) provides explicit anchor points for each sub-score. GPT-4o also cross-references German public registries from its training data.

Size / Impact Score (0–10) — 35% weight

Score rangeTypical profileExamples
9–10Major national org — thousands of employees, hundreds of millions € budgetDRK, Caritas, Diakonie
7–8Large regional or well-known national — hundreds of employees, tens of millions € budgetGreenpeace DE, AWO, Amnesty DE
5–6Medium-sized, established regional presence — dozens of employeesSector-specific NGOs with regional offices
3–4Small but operational — handful of employeesSingle-city local organizations
1–2Very small local initiative or volunteer-onlyNewly founded city initiatives
0Cannot determine / appears to be a single projectPlaceholder pages, dead websites

Mission + AI Applicability Score (0–10) — 35% weight

Score rangeCriteria
9–10Fascinating mission where AI could be transformative — mental health chatbots, disaster prediction, accessibility tech, triage automation
7–8Strong social mission with clear AI use cases — data analysis, reporting automation, matching, knowledge management
5–6Good social mission with some AI potential but less obvious use cases
3–4Standard mission, limited or indirect AI applicability
1–2Very niche or unclear mission with minimal AI angle

Establishment / Track Record Score (0–10) — 30% weight

GPT-4o cross-references Vereinsregister (founding dates, legal form), DZI-Spendensiegel (trust/governance seal), and Deutscher Spendenrat membership from training data.

Score rangeCriteria
9–1050+ years, well-known institution, DZI seal holder
7–820–50 years, solid reputation
5–610–20 years, established
3–45–10 years
1–2Under 5 years or unclear history
0Cannot determine

Scoring philosophy: GPT-4o is instructed to be honest when it doesn't know an organization. Unknown German NGOs should receive low scores, not default medium. Quality over quantity.

Enrichment Crawl Strategy

The enrichment agent starts from the NGO's homepage and discovers internal links to crawl in priority order. This is defined in TARGET_PAGES in agents/ngo_enrichment_agent.py:

PriorityPage typeURL pattern keywords searched
1Impressumimpressum, imprint, legal
2About / Who we areueber-uns, über uns, about-us, wer-wir-sind
3Team / Staffteam, unser-team, staff, mitarbeiter
4Leadership / Boardvorstand, leadership, management, geschäftsführung, gremien
5Contactkontakt, contact, ansprechpartner
6Digital / Innovationdigital, innovation, it, technologie
7Organization structureorganisation, struktur, organigramm

For each page, the agent fetches up to the first 5000 chars of stripped body text and sends it to GPT-4o structured extraction. The output is a ContactExtraction Pydantic model with contact_name, contact_role, contact_email, email_confidence (0–10), and contact_notes.

Contact preference logic: The prompt instructs GPT-4o to prefer senior decision-makers (Geschäftsführung, Vorstand, Digitalization leads, Innovation managers). Press/fundraising contacts are only selected when no better option exists. If no email is found, email_confidence = 0 and the field is left blank for manual follow-up.

German Copywriter Rules

The full system prompt is embedded in SYSTEM_PROMPT_TEMPLATE in agents/ngo_copywriter_agent.py. Key rules new students must know:

RRR Framework (mandatory structure)

  1. Relevance (Para 1): Greeting + intro (sender from TUM Social AI) + ONE specific appreciation sentence for their work area. Hard limit: one flattery sentence. Use "sehr inspirierend!" as the default phrase. Avoid "äußerst", "umfangreich", "von unschätzbarem Wert".
  2. Reward (Para 2–3): One sentence on what TUM Social AI does for nonprofits, then a personalized AI angle framed as an EXAMPLE ("könnte zum Beispiel"), followed by explicit openness to hear about their actual challenges.
  3. Request (Para 4): "Hätten Sie Interesse an einem kurzen 20-minütigen Austausch?" + invitation to forward to IT/Digitalisierung/Innovation colleague + closing signature.

Subject Line Format

TUM Social AI <> [NGO short name]: Pro-bono KI [optional 1-2 word German angle]

Examples:
  TUM Social AI <> WWF: Pro-bono KI Artenschutz
  TUM Social AI <> NABU: Pro-bono KI Biodiversität
  TUM Social AI <> Caritas Köln: Pro-bono KI
  TUM Social AI <> IOM Germany: Pro-bono KI Integration

Greeting Rules

SituationCorrect greeting
Contact person known, gender clearHallo Herr/Frau [Nachname],
Contact known, gender unclearHallo [Vollständiger Name],
No contact personLiebes Team von [NGO Name],
Never use"Sehr geehrte Damen und Herren" or any English greeting

Style Guardrails

  • 90–150 words ideal; hard max 170 words. 4 short paragraphs max.
  • Tone: thoughtful, concise, warm, intellectually credible, nonprofit-sensitive.
  • Never use: "revolutionieren", "disrupten", "bahnbrechend", "Gamechanger", em dashes (—), en dashes (–).
  • AI angle is always framed as an example ("könnte zum Beispiel"), never a certainty.
  • Never claim TUM Social AI already worked with this specific NGO unless it's true.
  • Never make up facts not present in the input data.

Sender Assignment

Owners are assigned by rank index from NGO_OWNERS = ["Carlo Renner", "Lisa Gavrilova"]. Even-index NGOs (rank 1, 3, 5…) go to owner 0; odd-index (rank 2, 4, 6…) go to owner 1. This gives a ~50/50 split across any campaign. To change default owners, edit the list in ngo_copywriter_agent.py line 177.

NGO.base Scraping Guide

The primary tested source for campaign CSVs. Use the Instant Data Scraper Chrome extension.

  1. Open ngobase.org and apply filters: country, region, work area, and/or keyword.
  2. Activate Instant Data Scraper on the filtered results page.
  3. Check the detected table/card preview — confirm it's picking up organization rows, not navigation.
  4. Keep: organization name, profile/website URL, work area, sub-work area, location.
  5. Enable pagination only if the extension keeps detecting the same clean row pattern across pages.
  6. Export as CSV and save to data/inputs/. Name it descriptively: ngobase_germany_environment_2026-05.csv.
  7. Rename headers to match expected column names (see mapping below).
  8. Run the full pipeline with --dry-run first to validate.

How to Make Changes or Improvements

All prompts are plain text — most improvements require no Python changes. Always test with --dry-run --limit 5 first.

Changing the scoring weights

Open agents/ngo_partner_agent.py. Find the total_score calculation (search for 0.35):

total_score = 0.35 * size_score + 0.35 * mission_score + 0.30 * establishment_score

Adjust the multipliers — they must sum to 1.0. Example: to weight mission more heavily for a specific campaign, try 0.25 * size + 0.50 * mission + 0.25 * establishment.

Changing the qualification threshold or shortlist size

Pass --min-score and --top as CLI arguments — no code change needed:

python -m agents.ngo_partner_agent --csv my_ngos.csv --min-score 5 --top 40

Lower --min-score to 5 for thin pipelines. Raise --top if you want a larger enrichment batch.

Changing scoring anchor points (what earns a 9 vs a 6)

Edit the SYSTEM_PROMPT in agents/ngo_partner_agent.py — specifically the scoring guide bullet points under each criterion. These are the anchor examples GPT-4o uses to calibrate its scores. Adding concrete German NGOs as examples improves calibration significantly.

Adding or removing enrichment pages

Edit the TARGET_PAGES list in agents/ngo_enrichment_agent.py (line 63). Each entry is a tuple of keyword patterns and a page label. To prioritize a new type of page (e.g., karriere for recruiting contacts), add it with a priority position in the list.

Changing the crawl timeout or delay

Edit the two constants in agents/ngo_enrichment_agent.py:

REQUEST_TIMEOUT = 15   # seconds per request
FETCH_DELAY = 1.0      # seconds between requests (be polite to NGO servers)

Do not set FETCH_DELAY below 0.5. NGO websites are often small servers that rate-limit quickly.

Resuming a failed enrichment run

The agent writes data/ngo_partnerships/enrichment_progress.json after each NGO. If the run fails midway, re-run with:

python -m agents.ngo_enrichment_agent --start-from 20

This skips the first 20 already-enriched organizations and picks up where it left off.

Changing German email copy style or tone

Edit SYSTEM_PROMPT_TEMPLATE in agents/ngo_copywriter_agent.py. The sections to most commonly adjust are:

  • STYLE RULES — banned words, tone descriptors, punctuation rules
  • Email structure — paragraph breakdown and constraints
  • SUBJECT LINE RULES — format, examples, keyword rules
  • CRITICAL RULES — anti-hallucination guardrails

After editing the prompt, always generate --dry-run --limit 5 emails and read them in German. Ask a native speaker if possible before launching a live campaign with changed copy.

Changing email length constraints

Edit the NGOEmail Pydantic model field descriptions in agents/ngo_copywriter_agent.py:

class NGOEmail(BaseModel):
    email_subject: str = Field(description="... Max 10 words ...")
    email_body: str = Field(description="... 90-170 words. No signature block.")

Adding a new sender / changing default owners

Edit NGO_OWNERS = ["Carlo Renner", "Lisa Gavrilova"] in agents/ngo_copywriter_agent.py (line 177). Add names to the list — assignment rotates by rank index, so a 3-person list gives a ~33/33/33 split. Pass --sender "Name" at runtime to override for a specific run.

Adding a new Notion field to the import

Open agents/notion_import_ngos.py. Find the properties dict being built before each Notion API call. Add your new field. Run --dry-run first — if the field doesn't exist in Notion, the API will return a 400 validation error that tells you exactly which property is missing.

Improving email quality via the learnings loop

After a campaign, add weak email examples and improved versions to the Notion Copywriter Improvement Log (two toggles: not yet processed / processed). Each entry needs: bad snippet, improved version, reason it was bad, and campaign/NGO context. Then distill the learnings into data/prompts/outreach_learnings.md. The copywriter auto-injects this file on every run via OUTREACH_LEARNINGS_MD.

Adding a new source beyond NGO.base

The pipeline accepts any CSV with the required columns. Steps:

  1. Scrape or export the new source (DZI, GlobalGiving, EU Transparency Register, etc.).
  2. Map the columns to: ngo_name, col href, work_area, sub_work_area, listing_locations.
  3. Drop the CSV into data/inputs/ with a descriptive name.
  4. Run --dry-run to validate the scoring quality. Adjust the prompt anchor points if GPT-4o scores the new source's organizations inconsistently.

Copywriter Improvement Log

Use two simple toggles in Notion: not yet processed and processed. Each item should include:

  • The bad snippet (exact text)
  • An improved version
  • The reason it was bad (too long, wrong tone, hallucinated fact, generic appreciation, etc.)
  • Campaign ID and NGO name for context

Once processed, distill learnings into data/prompts/outreach_learnings.md. The copywriter auto-loads this file at runtime — no code change needed.

Common failure patterns to watch for: using "sehr geehrte Damen und Herren", using two appreciation sentences instead of one, AI angle written as a certainty instead of an example, email body over 170 words, subject line longer than 10 words, or any sentence with "revolutionieren" / "disruptiv".
